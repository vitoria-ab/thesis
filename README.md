# Directory organization
1. **setup**: Deals with downloading CoLoRe and configuring, creating a copy of the environment used by Roger, and other specificities to the code.
2. **running_colore**: Has two files, *colore_inputs_(NAME).py* (which creates the necessary files to later input into CoLoRe; these are changed as necessary), and *run_colore.sh* (runs CoLoRe with the inputs inside the specified folder). This folder also stores the results (colore outputs + later plots) in folders called *results_(NAME)*.
3.  **cleaning_colore_output**: Has two files, *merge_galaxy_catalogs.py* (merges node outputs into a single .fits file), and *plots_colore.py* (plots the inputs and outputs generated by CoLoRe for some initial debugging in case things aren't working correctly).
4.  **data_analysis**: Has one file, *galaxy_plots_sliced.py* (generates density + overdensity plots and redshift histogram for a given slice in redshift).
