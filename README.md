# Directory organization
1. **setup**: Deals with downloading CoLoRe and configuring, creating a copy of the environment used by Roger, and other specificities to the code.
2. **running_colore**: Has four files: *colore_inputs.py* (which creates the necessary files to later input into CoLoRe; this is changed as necessary); *run_colore.sh* (runs CoLoRe with the inputs inside the specified folder); *merge_galaxy_catalogs.py* (merges node outputs into a single .fits file), and *plots_colore.py* (plots the inputs and outputs generated by CoLoRe for some initial debugging in case things aren't working correctly). This folder also stores the results (colore outputs + later plots) in folders called *results_(NAME)*. 
4.  **data_analysis**: Has four files: *galaxy_plots_sliced.py* (generates density + overdensity plots and redshift histogram for a given slice in redshift); *galaxy_cls_anafast.py* (calculates cls using a pixelated galaxy distribution with anafast); and *galaxy_cls_heracles.py* (calculates cls using an unbiased discrete estimator with heracles).

# Code flow
At each step, the *<NAME.py>* file is called using `sbatch <NAME.sh> <folder> <zmin> <zmax>` where *zmin*,*zmax* give the redshift range to consider (needs to be within the redshift arrays given in the CoLoRe input), and *folder* is the prefix to the results folder (named *results/<folder>_<zmin>-<zmax>*).
1. Generate CoLoRe inputs using *running_colore/colore_inputs.py* (alter parameters as desired), and choose the <folder> name of the results folder (later use always this name when calling the other files);
2. Run CoLoRe using *running_colore/run_colore.sh*;
3. If doing galaxy catalogs, merge the .fits files using *running_colore/merge_galaxy_catalogs.py*;
4. Plot the input and output files using *running_colore/plot_colore.py* (choose between plotting galaxy or HI maps within the file by commenting out what is not necessary);
5. Plot within the sliced interval using *data_analysis_galaxy/galaxy_plots_sliced.py*;
6. Calculate Cls with a given package using *data_analysis_galaxy/galaxy_cls_<package>.py* (options are: Anafast, Heracles and NaMaster);
7. Calculate theoretical Cls with CAMB using *data_analysis_galaxy/galaxy_cls_theory.py*.
